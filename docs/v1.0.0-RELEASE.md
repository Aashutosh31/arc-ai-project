# 🚀 ARC-AI v1.0.0 Release Notes

Welcome to the first stable public release of **ARC-AI** (v1.0.0). This release focuses on security hardening, runtime reliability, developer experience, and production-ready deployments.

---

## 🛡️ Security Hardening

- **QuickJS WebAssembly Sandboxing:** Replaced the deprecated and vulnerable `vm2` library in `executeCode.js` with a robust WebAssembly execution sandbox (`quickjs-emscripten`). Code executed by the LLM now runs in virtualized memory space, resolving the Remote Code Execution (RCE) release blocker.
- **Mandatory Token Encryption Key:** Enforced `GOOGLE_TOKEN_ENCRYPTION_KEY` as a strictly required environment variable. The backend now fails-fast and exits on startup if this key is missing, eliminating security fallback vulnerabilities.
- **Dynamic CORS Handler:** Replaced static CORS wildcards (`'*'`) with a dynamic origin resolver. This resolves the browser validation bug when combining wildcards with credential transmission (`credentials: true`), keeping credential storage secure in both production and development.

---

## ⚡ Runtime Reliability & Resource Management

- **WhatsApp Process Leak Prevention:** Implemented an activity-aware idle timeout reaper in `clientManager.js`. Headless Chromium browsers are automatically terminated after 5 minutes of inactivity, preserving system RAM and CPU.
- **Graceful Shutdown Lifecycles:** Added signal listeners (`SIGINT`, `SIGTERM`) in `index.js` to execute clean resource teardowns. When the server exits:
  - All incoming HTTP and Socket.io requests are terminated.
  - Active WhatsApp and Puppeteer processes are destroyed in parallel using `Promise.allSettled`.
  - MongoDB connection streams are closed safely.
- **Race Condition Resolutions:** Synchronized client destruction and recovery hooks to prevent sockets from binding to dying WhatsApp client records.

---

## 📦 Developer & Self-Hosting Onboarding

- **Portability Improvements:** Replaced workstation-specific host paths in `docker-compose.yml` with a portable, relative bind mount (`./.whatsapp-sessions`). The stack is now fully deployable out-of-the-box.
- **Environment Configuration Templates:** Created comprehensive `.env.example` templates in the root and `server` folders documenting all mandatory and optional configurations (e.g. LLM routing, models, and timeouts).
- **Git Ignore Safeguards:** Configured git ignoring rules to allow tracking of environment template files while securely keeping all `.env` secrets excluded.
